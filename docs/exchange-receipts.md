# 거래별 시제와 일요일 정산 안내

완료된 환전은 구글 시트의 거래 행을 확인한 후 텔레그램에 전체 현재 시제와 주간 수익을 답장합니다. 추가 AI 호출 없이 기존 정산 조회 한 번으로 집계합니다.

- 동 시제는 동 현금과 베트남 계좌 합계이며 두 금액을 별도로 표시합니다.
- USD 현금, 원화 계좌 잔액도 해당 거래에서 변동이 없어도 항상 표시합니다. USD는 저장된 센트를 달러로 변환합니다.
- 이번 거래 수익과 이번 주 누적 수익을 구분합니다. 수수료 + 확인된 실현환차익 - 비용이며, 원금·시제 보충/회수·외화 미실현 평가이익은 제외합니다.
- 주간 집계는 베트남 시간 월요일 00:00부터 조회 시점까지입니다. 정산 예정일은 해당 주 일요일이며, 시제 보관자는 지원, 정산 상대는 Danny입니다.
- 일요일이 되거나 월요일로 넘어가도 돈을 송금하거나 시제를 차감하거나 정산 완료 기록을 만들지 않습니다. 과거 주간 기록도 그대로 보존합니다. 실제 지급 완료와 금액은 별도로 확인해야 합니다.
- 늦게 전달된 답장도 현재 베트남 날짜의 주간 집계를 사용합니다. 한 번의 정산 RPC 조회 시점에 일치하는 잔액과 수익을 표시합니다.
- 원가 미확인 처분, 미해결 입력, 기록 시작 전 기간은 미확정으로 표시합니다. 잔액/집계 조회 실패 시 임의의 0 또는 성공 알림을 보내지 않고 재시도합니다.

이번 변경은 답장 형식과 집계 조회만 수정합니다. 봇 인증, 연결 권한, 장부 구조, 예약·회계 에이전트는 변경하지 않습니다. 라이브 연결 및 시작 시제 확정 전에는 실제 업무 가동으로 간주하지 않습니다.
